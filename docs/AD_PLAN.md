# Launch ad plan

**Goal:** spend a small, fixed amount to find out whether Roblox players click the game and stay. Then spend more only if they do. Ads can't fix a game that players leave, so we measure first.

Roblox changes its ads tools often. If a screen doesn't match these steps, follow what the dashboard shows and keep the same plan: **small test → check numbers → scale or fix**.

## Before spending anything

1. **Wait 3–5 days after launch** and let the free players come in. Make sure there are no game-breaking bugs (check **Analytics → Errors**, and send me anything red).
2. **Fill in the Questionnaire** (Maturity & Compliance). Ads won't run without a rating.
3. **Pick the thumbnails.** On the game's **Places / Thumbnails** page, put these first:
   1. `mail-a-tiger-discovery-thumbnail.png`: the action shot with the title, and the best first impression.
   2. `mail-a-tiger-key-art-no-text.png`: clean art, as the second slide.
   - Don't use `mail-a-tiger-sky-mail-update-thumbnail.png` yet. It says "SKY MAIL UPDATE", which isn't a real update, and misleading thumbnails get flagged and annoy players.
4. **Icon:** `mail-a-tiger-game-icon.png` (already done).
5. **Optional: test thumbnails for free first.** If the dashboard's **Experiments** page offers thumbnail or icon testing, run the discovery thumbnail against the key art for a week. Roblox shows each to different players and tells you which gets more clicks.

## The ad itself: a Sponsored Experience

Creator Dashboard → **Ads Manager** (or ads.roblox.com) → **Create campaign** → objective **Visits** (or "Sponsored experience").

| Setting | Pick |
|---|---|
| Experience | Mail a Tiger |
| Budget | **$5 a day** (or the smallest amount it allows) |
| Length | **5 days** (about $25 total) |
| Devices | All (the game works on phone, PC and console) |
| Ages | Everyone the game is rated for (all ages once the human review clears; 13+ until then if it asks) |
| Regions | All, or the US/UK/Canada/Australia first if it lets you choose |
| Creative | It uses your icon and thumbnails, so step 3 above *is* the ad |

**Turn on Rewarded video ads? No.** Leave the game ad-free for now.

## Reading the results (after 5 days)

Look in Ads Manager for the campaign numbers, and in **Analytics** for what players did.

| Number | Where | Good | Bad, so fix this first |
|---|---|---|---|
| Click rate (clicks ÷ impressions) | Ads Manager | 2%+ | Under 1%: the **thumbnail or icon** isn't grabbing people. Try the other one. |
| Cost per visit | Ads Manager | under about $0.05 | Very high: same fix as above |
| Average session length | Analytics → Engagement | 8+ min | Under 4 min: players are confused or bored early. Send me the numbers. |
| Day 1 retention | Analytics → Retention | 10%+ | Under 5%: the first 10 minutes need work before spending more |
| Paying users | Analytics → Monetization | any | — (too early to judge) |

**What to do next:**
- **Good click rate and good retention:** double the budget ($10–20/day) for another week, and keep doubling while the numbers hold.
- **Good click rate, bad retention:** stop ads, send me Analytics screenshots, and I'll fix the start of the game.
- **Bad click rate:** swap the thumbnail and icon, then run another $25 test.
- **Never** spend more than you're happy to lose. A $25 test is the price of the information.

## Best times to run ads

- **Weekends** (Friday afternoon to Sunday): the most Roblox players.
- **Right after an update:** change the title to e.g. `Mail a Tiger [UPDATE 🆕]` so returning players notice too.
- School holidays.

## Free boosts that work alongside the ads

- Post a clip on TikTok / Shorts the same day the ad starts. The ad brings people, the clip makes it feel popular.
- Players' invites now pay diamonds (see the README), so every new player can bring friends.
- The in-game ⭐ Favorite / 🔔 Get updates prompt helps Roblox's algorithm. Favorites and returning players count for more than ad clicks.
