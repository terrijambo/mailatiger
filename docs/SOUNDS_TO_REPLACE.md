# Sounds to replace

Every sound id lives in `src/shared/Config/Sounds.luau`. The starter sounds are Roblox's own library audio, picked **by name, not by ear**, so this list is based on what each one is called versus what it's used for. Trust your ears over this list.

How to swap one: Studio → Toolbox → Marketplace → Audio → search → right-click → Copy Asset ID → paste it as `Id = "rbxassetid://..."`.
